# Expense Tracker — Requirements

## 1. Purpose

Expense Tracker is a web application that allows users to record and manage their income and expenses. Users can categorize transactions and view summaries of their financial activity over time.

## 2. Users

| User | Purpose |
| --- | --- |
| Registered User | Manage their own income, expenses, transactions, and financial summaries |

## 3. Core Use Cases

- Register an account
- Log in
- Record an income
- Record an expense
- View transactions
- Edit a transaction
- Delete a transaction
- Categorize transactions
- Search transactions
- Filter transactions
- View financial summary
- View monthly summary
- View dashboard
- Log out

## 4. Features in Scope

- User Registration & Login
- JWT Authentication
- Expense Management
- Income Management
- Expense Categories
- Income Categories
- Create, View, Update & Delete Transactions
- Transaction Filtering
- Transaction Search
- Date-based Filtering
- Expense & Income Summary
- Monthly Financial Summary
- Dashboard
- Pagination
- Input Validation
- Error Handling
- Responsive UI
- Logout

## 5. MVP Scope

The MVP will provide authenticated users with the ability to record, categorize, search, filter, update, and delete income and expense transactions, and view financial summaries through a dashboard.

## 6. Out of Scope

The following features are outside the scope of this MVP:

- Bank account integration
- Online payments
- Automatic transaction import
- Investment tracking
- Budget alerts/notifications
- Multiple currencies
- Mobile application
- Advanced financial analytics
- Export to Excel/PDF

## 7. Scope Boundary

The project will focus on delivering a functional full-stack web application within the planned development time. Features outside the MVP scope will not be implemented unless required to complete the core application.
